Waymark is a point-of-sale system for small stores that also helps the owner decide what to do next. It started from interviews with four retailers.

## My role

Waymark is a solo build. I am the founder, I ran the interviews with the four retailers, and I write the software.

## Approach

Waymark has two parts: an offline till and an Admin app. It is built with C#, .NET and Avalonia on SQLite, with React and TypeScript.

One example of the decision support is the expiry alert. Stock is tracked per batch, so the system knows which units expire first and can warn the owner while there is still time to act.
